# rotation

Rotation is a lightweight iMessage <> Spotify bot built on Spectrum, Convex,
Spotify Web API, Stripe Payment Links, and the Vercel AI SDK Google provider.

## Spotify

Use this redirect URI in the Spotify app:

```text
https://precise-toad-279.convex.site/auth/spotify/callback
```

Required scopes are generated by the app: profile/email, library and playlist
read, top tracks, playback read, and playlist modify.

Set these in both local `.env` and Convex env. The encryption key must match in
both places because Convex stores the OAuth tokens and the bot decrypts them.

```sh
npx convex env set SPOTIFY_CLIENT_ID <client-id>
npx convex env set SPOTIFY_CLIENT_SECRET <client-secret>
npx convex env set SPOTIFY_TOKEN_ENCRYPTION_KEY <shared-long-random-secret>
```


## Deploy

Convex hosts the database plus the Spotify OAuth and Stripe webhook HTTP routes.
The Spectrum iMessage listener is a long-running stream, so it should run as an
always-on Node worker rather than inside a Convex function.

Railway is the simplest production target:

```sh
npm install
npm run start
```

Set the same `.env` values in Railway. Keep `CONVEX_URL` and
`CONVEX_SITE_URL` pointed at the linked Convex deployment.

## Notes

Spotify's public recommendations/audio-feature endpoints are not used. Rotation
builds playlists from the user's saved/top/playlist context, AI-generated search
queries, Spotify catalog search, and AI track selection.
